# ⚡ TypeBattle

TypeBattle is a real-time multiplayer typing race application where users can improve their typing speed and compete with other players.

The project combines typing practice with real-time multiplayer gameplay, including live race progress, countdowns, WPM, and accuracy tracking.

---

## 🚀 Features

### ⌨️ Typing Practice
- Monkeytype-inspired typing interface
- Real-time character validation
- Correct characters highlighted in green
- Incorrect characters highlighted in red
- Cursor tracking
- Timer-based typing sessions
- Real-time WPM calculation
- Accuracy calculation

### 🏁 Multiplayer Typing Race
- Create and join typing rooms
- Real-time multiplayer gameplay
- Player ready system
- 3-2-1 countdown before the race
- Same text for all players
- Live race progress
- Race completion tracking
- Final results and winner comparison

### ⚡ Real-Time Communication
- Socket.IO based real-time communication
- Instant synchronization between players
- Room-based multiplayer architecture
